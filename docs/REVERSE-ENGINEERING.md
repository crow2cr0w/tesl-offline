# Offline server implementation

The build embeds a managed payload and dependencies into a verified retail assembly and injects a bootstrap. The local host handles matchmaking and match responses using runtime game types. Runtime rule and FX mappings are supplied in `data/`.

The game and its original assemblies are not relicensed by this project. The build requires a separately obtained compatible retail installation. Not all gameplay paths or visual effects have been verified; tests and simulator results cover only the scenarios they execute.
